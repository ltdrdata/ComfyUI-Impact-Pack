# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues, discussions or pull requests.

Private vulnerability reporting is enabled for this repository:

1. Open https://github.com/ltdrdata/ComfyUI-Impact-Pack/security/advisories/new
   (or the **Security** tab → **Report a vulnerability**).
2. Fill in the form:
   - **Title** and **Description**: what the problem is, the steps or a proof of concept to reproduce it, and the impact.
   - **Affected versions**: the Impact Pack version or commit you tested, and the ComfyUI version.
   - **Severity** and **Weakness (CWE)** if you can assess them; leaving them empty is fine.
3. Submit. The report is visible only to you and the maintainers, and it is where the issue is discussed and a fix is worked on.
